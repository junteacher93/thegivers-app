sns-uploader

A private publishing tool for the YouTube channel TheGivers (더기버스)

sns-uploader is a desktop application that the channel owner runs on their own computer to upload and schedule their own educational personal-finance videos on their own YouTube channel, and to time related Instagram and Threads posts. It has no other users and no public sign-up.

What it uses

  • YouTube Data API v3 — uploading the owner's own videos and thumbnails, and reading the owner's own channel upload list to check scheduled publish times.

This application uses YouTube API Services. By using it you agree to the YouTube Terms of Service.
