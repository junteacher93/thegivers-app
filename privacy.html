Privacy Policy — sns-uploader

Last updated: October 21, 2026

About this application

sns-uploader is a private desktop tool operated by the owner of the YouTube channel "TheGivers (더기버스)". It runs only on the owner's personal computer and is used only by the owner to upload and schedule the owner's own videos on the owner's own YouTube channel. It has no other users.

Data accessed through YouTube API Services

  • Uploading the owner's own video files and thumbnails to the owner's channel.
  • Reading metadata of the owner's own channel uploads (video titles, scheduled publish times and privacy status) to coordinate publishing times.

The application does not access, collect or store any data about other YouTube users.

How data is stored and shared

  • OAuth access tokens are stored only on the owner's local computer.
  • No data obtained through YouTube API Services is sold, shared with or transferred to any third party.
  • Channel metadata read by the application is used only on the owner's computer to schedule related social media posts. A local cache of this list is overwritten on every check.

Revoking access

Access can be revoked at any time from the Google Account security settings page: https://myaccount.google.com/permissions. Deleting the local token file also removes the application's access.

Google and YouTube policies

This application uses YouTube API Services. By using it, the user agrees to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.
